# Credit Scoring Model - ML Approach

## Overview
Built a machine learning model to assess credit risk and predict loan defaulters, helping financial institutions make better lending decisions.

## Workflow
- Data Cleaning & EDA
- Feature Engineering & Encoding
- Model Training: Logistic Regression, Random Forest, XGBoost
- Evaluation: Accuracy, Precision, Recall, F1, ROC-AUC Curve

## Tech Stack
Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Jupyter Notebook

## How to Run
pip install -r requirements.txt
jupyter notebook
